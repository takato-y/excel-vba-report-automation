## 1. 背景・目的

月ごとの売上データが、部署や取引先ごとに別々の CSV / Excel ファイルで届く業務を想定する。
現状は担当者が毎月ファイルを開いて手作業でコピーし、顧客別・商品別の集計表を作って PDF にしている。
この作業には次の問題がある。

- 貼り付け漏れ・二重貼り付けに気づきにくく、集計値の誤りが報告書まで残る
- 日付の書式違いや数値に文字が混ざった行があると、関数がエラーになり原因探しに時間がかかる
- 作業手順が担当者の頭の中にあり、引き継ぎが難しい

本ツールは、フォルダに置いたファイルをボタン1つで取りまとめ、集計・帳票作成・PDF 出力までを行う。
誤りのある行は止めずに一覧へ出し、どのファイルの何行目を直せばよいかが分かる状態にする。

## 2. 機能要件

| ID | 要件 | 優先度 |
|---|---|---|
| REQ-001 | 指定フォルダ内の複数の売上ファイル（CSV・Excel）を一括で読み込める | 必須 |
| REQ-002 | 読み込み時に見出し・日付・必須項目・数値・金額の整合を検査し、取り込めない行をファイル名・行番号・理由つきで一覧にする | 必須 |
| REQ-003 | 取り込んだ全明細を1つのシートに統合し、取込元ファイルが分かるようにする | 必須 |
| REQ-004 | 顧客別・月別の売上を集計する | 必須 |
| REQ-005 | 商品別の数量・売上を集計する | 必須 |
| REQ-006 | 集計結果を帳票（表題・対象期間・合計・消費税・税込合計・条件付き書式）として出力する | 必須 |
| REQ-007 | 帳票を PDF ファイルとして出力フォルダに保存できる | 必須 |
| REQ-008 | 入力フォルダ・出力フォルダ・CSV の文字コード・消費税率・PDF 出力の有無を設定シートで変更できる | 必須 |
| REQ-009 | 1つのボタンで全処理を実行し、結果（件数・エラー件数・PDF の保存先）を画面で知らせる | 必須 |

## 3. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| REQ-101 | 性能 | 読み込みと書き出しはファイル・シート単位で配列にまとめて行い、セルを1つずつ読み書きしない。1万行程度の明細を実用的な時間で処理できること |
| REQ-102 | エラー処理 | 想定できるエラー（フォルダが無い・ファイルが無い・設定値の誤り・PDF の書き込み失敗）は、原因と対処を日本語で表示する。途中で失敗しても、画面更新・再計算の設定を元に戻す |
| REQ-103 | 保守性 | 設定値はセル番地ではなく名前で参照し、表の位置を変えてもコードの修正を不要にする。処理は役割ごとのモジュールに分け、ソースはテキストファイルで差分を追えるようにする |
| REQ-104 | テスト容易性 | メッセージ表示を止めた状態でも同じ処理経路を実行でき、集計結果を自動で検算できること |

## 4. 対象外

- 入力フォルダの下位フォルダにあるファイル
- セルの中に改行を含む CSV（1行1明細の CSV のみを対象とする）
- 2枚目以降のシート（Excel ファイルは先頭シートのみ読む）
- 品目ごとに税率が異なる計算（軽減税率）。消費税は税抜合計に1つの税率を掛けて算出する
- Mac 版 Excel・Excel Online での動作
- 紙への印刷（PDF の作成までを範囲とする）

## 5. 前提・制約

- 入力ファイルの見出しは「日付, 顧客名, 商品名, 数量, 単価, 金額」の6列とする
- 消費税の端数は切り捨てとする
- 本リポジトリのデータはすべて架空のものである
