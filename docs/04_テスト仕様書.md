## 1. 方針

- **実機の Excel で動かして確かめる。** `tests/run_tests.py` が配布用ブックの写しを Windows の一時フォルダに置き、設定シートに値を入れて［レポート作成］ボタンと同じ処理（`RunReportCore`）を実行する
- **期待値は VBA とは別に計算する。** `tests/expected.py` が同じ入力ファイルを Python の標準 csv モジュールと openpyxl で読み、要件定義書の検査規則に従って集計する。VBA の実装は写していない
- 帳票の数値は、見出しの文字（「顧客名」「商品名」「合計」など）を手がかりに読み取り、セル位置を決め打ちしない
- テスト中はメッセージボックスを出さず、結果の文言を「前回の実行結果」から読む（FN-008）

## 5. 自動テストで確かめていない項目

| 項目 | 理由 | 確認方法 |
|---|---|---|
| 条件付き書式の色・赤字の位置 | セルの値として読み出せないため | 帳票を画像に書き出して目視で確認（前月より減った4セルだけが赤字であることを確認済み） |
| ボタンを押したときのメッセージボックス | 画面を表示しない実行では表示を止めているため | 処理の経路はテストと同じ。文言は「前回の実行結果」と同一 |
| ファイルを開けない場合（ERR-101）と予期しないエラー（ERR-900） | 再現用のファイル（ロック中・破損）を安定して用意できないため | エラー処理の経路はコードレビューで確認。自動テストは未実施 |
| 別のパソコン・プリンター環境での PDF 出力 | 上記の環境1台でのみ実施 | 導入時に1回実行して確認する（導入・運用手順に記載） |
